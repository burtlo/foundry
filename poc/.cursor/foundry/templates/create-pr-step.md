# Create pull request (foundry delivery)

Run in **`{app_folder}`** after human approves commit/push (or includes push in approval).

Use `{issue_key}`, `{developer_first_name}`, `{site_url}` from FactoryConfig / ticket packet / FactoryRunState.

**Parent only** runs Foundry CLI via `foundry-invoke` fences. Do not re-parse `team-variables.md`.

---

## PR title (required)

Resolve `{issue_key}` from FactoryRunState. If missing and `jira.enabled` is true:

```foundry-invoke
issue-key parse --text "{kickoff or browse URL}" --pattern "{jira.issue_key_pattern}"
```

Then:

```foundry-invoke
pr-title --issue-key "{issue_key}" --summary "{Jira Summary}" --pattern "{git.pr_title_pattern}" --jira-enabled true
```

Free-text mode (`jira.enabled: false`, no key):

```foundry-invoke
pr-title --summary "{approved story or goal phrase}" --jira-enabled false
```

If the CLI returns `INVALID_CONVENTIONAL_COMMIT_TITLE` or `MISSING_ISSUE_KEY`, **stop** — do not run `gh pr create`. Show the human the CLI `message`.

Show the resolved title to the human before `gh pr create`. Store it on FactoryRunState as `resolved_pr_title`.

---

## Default branch

```foundry-invoke
git default-branch --repo "{app_folder}"
```

Use the JSON `default_branch` (short name) as `--base`. Never `origin/main`.

---

## GitHub CLI (preferred)

```text
gh --version
```

Build `{pr_body_markdown}` in-agent with these sections, then run:

```text
gh pr create --title "{resolved_pr_title}" --body "{pr_body_markdown}" --base {default_branch}
```

**Body outline** (agent judgment — not generated by the CLI):

```markdown
## Summary
{What this PR does}

## Jira Ticket
[{issue_key}]({site_url}/browse/{issue_key})

## Changes Made
- {areas changed}
- Tests added/updated
- AGENTS.md updated: {yes/no — list files}
- PRD regenerated: {yes/no — path}

## Testing
- [x] Build and tests pass (per factory run)
- [ ] Manual testing if applicable

## Checklist
- [x] Matches AGENTS.md patterns
- [x] Validator findings addressed or waived
- [x] Pre-PR Cursor review (Step 7c): {Bugbot summary}; {Security summary} — when Step 7c ran
- [x] Developer approved before push
```

---

## Without GitHub CLI

```text
git config --get remote.origin.url
```

Rewrite `git@github.com:` to `https://github.com/` and strip a trailing `.git` in-agent. Compare URL:

`{REPO_URL}/compare/{default_branch}...{branch}?expand=1`

Provide copy-paste **title** (`{resolved_pr_title}`) and PR body (same sections as above).

---

## After create

Record `pr_url` on the run; continue delivery-check / ship steps.
