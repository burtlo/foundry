# Foundry CLI

Python package for the workflow engine: CLI entry (`foundry.py`, `foundry.sh`), library (`foundry_cli/`), and pytest suites (`tests/unit/`, `tests/acceptance/`).

| Path | Role |
|------|------|
| `foundry_cli/` | Importable library |
| `foundry.py` | CLI entry point |
| `foundry.sh` | Shell wrapper |
| `tests/acceptance/features/` | Gherkin acceptance contracts |
| `run_acceptance.sh` | Wrapper for `dev acceptance` |

Developer setup, `just` recipes, flags, and examples: [repository README](../../../README.md).

Acceptance tests: [tests/acceptance/README.md](tests/acceptance/README.md).
